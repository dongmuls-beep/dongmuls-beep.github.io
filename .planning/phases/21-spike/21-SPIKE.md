# Phase 21 게이트 0 스파이크 판정 기록

작성일: 2026-11-11 (plan 21-01, 공개 근거 부분). 실호출 항목은 plan 21-02에서 채운다.

## 개요 (재범위 전제)

- 2026-11-11 재범위: 공개 사이트에 종가를 올리지 않는다. 관리자 1명이 이 PC에서 로컬로만 쓴다. 로그인·다국어·공개 내비·CI 수집·종가 커밋은 범위 밖.
- 대상 API: 금융위원회 증권상품시세정보(공공데이터포털 15094806), operation "ETF시세".
- 서비스키는 이 문서에 기록하지 않는다. 환경변수 이름은 `DATA_GO_KR_KEY`.

## SPIKE-01 이용허락 판정

출처: https://www.data.go.kr/data/15094806/openapi.do (2026-11-11 직접 재조회 성공, 페이지 수정일 2026-10-28)

원문 인용:

> ※ 본 개방데이터는 공공누리 4유형임을 참고하시기 바랍니다. 이용허락범위 제4유형 : 출처표시 + 상업적 이용금지 + 변경금지 본 데이터는 상업적 목적 여부와 상관 없이 제3자 무단 제공 및 재배포가 엄격히 금지됩니다. 만약 상업적 목적으로 이용할 경우 원천 소유자인 한국거래소의 KRX Data Marketplace(data.krx.co.kr)에서 유료로 구매하여야 합니다.

메타 항목: "이용허락범위 공공저작물 : 출처표시, 상업적 이용금지, 변경금지 (제 4유형)", 비용 무료, 심의 개발/운영 모두 자동승인, 키워드 ETF,ETN,ELW. (RESEARCH에서 보인 메타데이터의 "제한 없음" 표기는 본문과 상충했으나 이번 본문 재조회에서는 4유형으로 일치 확인.)

판정: 조건부 적합 (관리자 개인 로컬 이용, 재배포 없음, 비상업). 근거: 금지 대상은 "제3자 무단 제공 및 재배포"이고 상업 이용이다. 관리자 1명이 자기 PC에서 조회·표시하는 것은 제3자 제공도 재배포도 상업 이용도 아니다. 단 이는 원문 문언에 대한 내 해석이며 법적 확정은 아니다(미확인: 금융위/KRX 공식 해석).

성립 조건 (Phase 22/25 제약으로 승계):
1. 종가 파일·가공 시계열을 git 커밋·공개 배포하지 않는다 (`local/portfolio/data/` gitignore).
2. 공개 사이트·Pages·sitemap에서 링크하지 않고 외부 노출하지 않는다.
3. 로컬 화면에 출처(금융위원회 증권상품시세정보, 한국거래소 원천) 표시.
4. 가공 데이터도 제3자에게 제공하지 않는다. 변경금지 조항상 원본 값을 임의 수정하지 않는다 (분할 보정은 하지 않음과 일치).
5. 광고·수익 목적 사용 금지 (이 앱은 광고 없음).

## SPIKE-03 백필 호출량·시간 추정

전제: 종목 59개(data.json 실제 개수 확인), 5년 약 1,240 영업일. 호출당 0.3~1초는 [ASSUMED]. 한도 10,000은 페이지 근거(개발계정).

시나리오 A (종목별 기간 조회 beginBasDt~endBasDt):

| P(numOfRows) | 호출 수 | 예상 시간(0.3~1초/호출) |
|---|---|---|
| 100 | 59 x 13 = 767 | 약 3.8~12.8분 |
| 1000 | 59 x 2 = 118 | 약 0.6~2분 |

시나리오 B (일자별 전체 ETF, 약 1,000종목/일 [ASSUMED]): 1,240일 x ceil(1000/P). P=1000이면 1,240 호출, P=100이면 12,400 호출(10,000 초과, 부적합).

권고: 시나리오 A. 한도 내(최대 767 < 10,000). 일일 증분은 종목별 59호출 또는 basDt 1일 전체 목록, 둘 다 한도 내. P 상한·실제 응답시간은 plan 02 실측.

## SPIKE-04 프런트 스택

결정: 바닐라 JS.

- 빌드 없음, 기존 전 페이지가 바닐라. `compare-chart.js` 순수 SVG 차트 패턴 재사용.
- 테스트는 기존처럼 node로 직접 실행하는 `tests/*_check.js` 방식.
- CDN 외부 JS 의존 없음 (React UMD+SRI는 첫 외부 JS 의존, 공급망 부담).
- React 미채택 이유: 행 목록 입력 수준의 폼에는 상태 관리 이점이 작고, 로컬 전용 앱이라 얻는 것이 없다. 런타임 Babel 금지 방침.
- 로컬 전용이므로 공개 사이트 통합 불필요. (SEED에 React 요청 이력이 있으므로 사용자 확인 항목으로 남긴다.)
