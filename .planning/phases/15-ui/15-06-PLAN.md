Create compare-calculator.js as an IIFE with "use strict", with no top-level declarations. Export `CompareCalculatorUI` on globalThis (fallback window).

parseNumberInput(value):
- A finite number is returned as-is. A non-string non-number returns NaN.
- For strings:
  1. `String(value).normalize("NFKC")` (guard with typeof String.prototype.normalize === "function"). This maps full-width digits, comma, period and minus to ASCII.
  2. Replace U+2212 with "-".
  3. Remove every whitespace, ",", "원", "%" and "년".
  4. If the result is empty, return null. If its length is > 32, return NaN.
  5. n = Number(result); return Number.isFinite(n) ? n : NaN.

readCalcParams(search): URLSearchParams on search. For each of amt->lumpSum, yrs->years, mon->monthly, ret->annualReturnPct, parse the param; null or NaN falls back to DEFAULTS. Return CompareCalc.normalizeInputs(values).

buildCalcSearch(search, inputs):
- n = CompareCalc.normalizeInputs(inputs), then p = new URLSearchParams(search).
- For each field, set the param when n[field] !== DEFAULTS[field], else delete it. Write the value as String(n[field]).
- Return "" if p is empty, else "?" + p.toString().replace(/%2C/gi, ","). This keeps compare lists readable; codes are [0-9A-Z] only.
URLSearchParams.set keeps the existing position of a param and appends new ones at the end; the asserted outputs rely on that.

buildCalcResult(inputs, items, baseCode, otherCode):
1. n = CompareCalc.normalizeInputs(inputs).
2. fees = items.map(i => ({ code: i.code, fee: isFinite(toFeeNumber(i.real)) ? toFeeNumber(i.real) : null })). Negative or garbage values become null, so they are excluded as fee_missing.
3. sims = CompareCalc.simulateMany(n, fees). perEtf = items zipped with sims: { code, name, excluded, reason, totalFees, fvWithFee, warning }.
4. excludedNames = names where excluded. warnings = names where warning === "fee_high".
5. contributed = sims[0].totalContributed, or n.lumpSum + n.monthly * n.years * 12 if there are no items.
6. Pair: a = item with baseCode, b = item with otherCode. If either is missing or excluded, or a === b, headline = null.
7. Otherwise c = CompareCalc.compare(n, feeA, feeB). If c.excluded, headline = null.
   - If Math.abs(c.feesDifference) < 1, headline = { kind:"same", years }.
   - Else headline = { kind:"more", years, low, high, amount: Math.round(Math.abs(c.feesDifference)) }, where high is b when feesDifference > 0 (b paid more), else a.
Record this assumption in the SUMMARY: "더 부담" = cumulative fees paid (totalFees difference), not the final-value difference.
