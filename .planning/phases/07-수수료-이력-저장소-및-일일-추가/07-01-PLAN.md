    - Next day same values -> changed_count 0, series unchanged

    - String input "0.05%" / "1,000" parsed via to_float; stored values are rounded floats
    - None, "" and "-" values -> no point written, existing last value preserved, no series/field created for a code whose first value is null
    - Code missing from snapshot -> its series and names entry remain untouched
    - Same-day rerun with same value -> changed_count 0 (no duplicate date)
    - Same-day rerun with different value -> today's point replaced in place (list length unchanged, new value)
    - Same-day rerun whose value equals the previous (pre-today) point -> today's point removed (no redundant point)
    - Name change for same code -> names[code] updated to new 종목명, series identical, changed_count 0
    - Alphanumeric code "0026S0" stored as string key; rows with blank 종목코드 are skipped
    - apply_snapshot does not mutate its input history argument (deep copy)

Module layout for scripts/build_fee_history.py:
- Module docstring; `from __future__ import annotations`; `from build_changelog import FIELDS, to_float` (per CONTEXT: reuse, scripts/ is on sys.path when run as `python scripts/build_fee_history.py`).
- Constants: DATA_FILE = Path("data.json"), HISTORY_FILE = Path("fee-history.json"), SCHEMA_VERSION = 1, KST = timezone(timedelta(hours=9)), ROUND_DIGITS = 6.
- kst_today() -> str: returns datetime.now(KST).date().isoformat() (per CONTEXT fixed +9 helper; no zoneinfo/tzdata).
- empty_history() -> dict: {"version": 1, "updatedAt": "", "names": {}, "series": {}}. Note validate_history must accept "" updatedAt only as a str (type check only).
- normalize(value) -> float | None: to_float(value); None stays None; else round(x, ROUND_DIGITS). "-" becomes None via to_float's float() failure.
- apply_snapshot(history: dict, rows: list[dict], date: str) -> tuple[dict, int]: deep-copy history; for each row, code = str(row.get("종목코드", "")).strip(), skip if empty; name = str(row.get("종목명", "") or "").strip(), set names[code] = name when non-empty (rename rule, HIST-02). For each field in FIELDS: v = normalize(row.get(field)); skip if None (null rule: keep previous). points = series.setdefault(code, {}).setdefault(field, []) — create lazily only when v is not None so null-only codes do not get empty lists. Rules: if points and points[-1][0] == date: if points[-1][1] == v -> no-op; elif len(points) >= 2 and points[-2][1] == v -> pop today's point (count +1); else replace points[-1] with [date, v] (count +1). elif not points or points[-1][1] != v -> append [date, v] (count +1). else no-op. If count > 0 set history["updatedAt"] = date. Codes absent from rows are left untouched (disappeared-code rule). Return (new_history, count).
- validate_history(obj) -> None: raise ValueError with a specific message for each schema violation listed in behavior; iterate series[code][field] lists and check each point is a list of length 2 with str date and int/float (not bool) value.
- load_history(path: Path) -> dict: if not path.exists() raise FileNotFoundError; json.loads(path.read_text(encoding="utf-8")) (let JSONDecodeError propagate); validate_history; return. Do NOT use build_changelog.read_json_file (per CONTEXT: no silent default).
- dump_history(history) -> str: json.dumps(history, ensure_ascii=False, sort_keys=True, separators=(",", ":")) + "\n".
- load_rows(path: Path) -> list: read data.json strictly; missing, invalid JSON, or non-list raises ValueError/FileNotFoundError.
- main(argv: list[str] | None = None) -> int: argv defaults to sys.argv[1:]; init = "--init" in argv. Wrap loading in try/except (FileNotFoundError, json.JSONDecodeError, ValueError) -> print(f"[ERROR] fee-history: {exc}", file=sys.stderr) and return 1, writing nothing. Init mode: if HISTORY_FILE exists -> [ERROR] refuse to overwrite, return 1; else history = empty_history(). Normal mode: history = load_history(HISTORY_FILE). rows = load_rows(DATA_FILE). new, count = apply_snapshot(history, rows, kst_today()). text = dump_history(new). Write HISTORY_FILE (encoding="utf-8", newline="\n" via write_text on text) only if init or text differs from existing file text; print "[fee-history] recorded {count} changes for {date}" or "[fee-history] no changes; kept existing fee-history.json". Return 0.
- Footer: if __name__ == "__main__": raise SystemExit(main()).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ETL output (data.json) -> build_fee_history.py | Scraped KOFIA/market data, produced by our own ETL; malformed values possible |
| fee-history.json on disk -> build_fee_history.py | Repo-tracked file; could be corrupted by bad merge or manual edit |
| CI job -> repo (git-auto-commit-action) | Workflow writes to main with GITHUB_TOKEN |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Tampering | load_history / fee-history.json | mitigate | Strict json.loads + validate_history; any error returns exit 1 before writing, so a corrupt file is never overwritten with an empty history (HIST-03) |
| T-07-02 | Tampering | apply_snapshot input values | mitigate | normalize() via to_float + round(6); null/unparseable values skipped, never stored as change; non-numeric points rejected by validate_history |
| T-07-03 | Denial of Service | daily workflow | accept | Failing fee-history step blocks that day's auto-commit; intended fail-closed behavior, operator fixes file and reruns via workflow_dispatch |
| T-07-04 | Information Disclosure | fee-history.json | accept | Contains only public ETF fee data; no secrets or PII |
| T-07-05 | Elevation of Privilege | workflow edit | mitigate | Only adds a python step and a file to file_pattern; no new secrets, permissions, or third-party actions; no new pip packages (no supply-chain surface) |
</threat_model>
