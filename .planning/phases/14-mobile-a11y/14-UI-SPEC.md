## 3. Color and Contrast

60/30/10 (existing light theme, unchanged): Dominant 60% `--bg #e8edf5` / `--surface #fff`; Secondary 30% `--surface-soft #f5f8fd`, glass panels `rgba(255,255,255,.72/.9)`; Accent 10% `--primary #0b57d0`.

Accent (`--primary`) reserved for: active tab text/border, primary CTA / `.btn-link` text+border, links (`.stock-link`, `.footer-links a`, breadcrumb links), `:focus-visible` outline, skip-link background, retry button text/border, hamburger open state. NOT for h1, skeleton, arrows, or body text.

## 5. Header Hide/Show Behavior Contract (A11Y-02)

Mechanism (already implemented, keep): `.site-header { position:sticky; top:0; transition: transform .3s ease }` + `.site-header.header-hidden { transform: translateY(-100%) }` (style.css:78-93). Never use `top` to hide. JS: `initSmartHeader()` script.js:172-202 (rAF-throttled scroll listener, `passive:true`).

Contract (state table):

| Condition | Header state |
|---|---|
| `scrollY <= 60` (page top) | always visible |
| Scrolling down, `scrollY > 60`, delta > 0 | hidden (`.header-hidden`) |
| Scrolling up (any delta < 0) | visible |
| `body.nav-open` (drawer open) | visible, and scroll handler returns early (BUG-01/D-04, already in code script.js:186-194) |
| Focus is inside `.site-header` (hamburger, nav links, language select, logo) | **visible - REMAINING** |
| Focus moves into header via Shift-Tab from `<main>` while header hidden | header re-shown immediately - **REMAINING** |
| `prefers-reduced-motion: reduce` | no slide animation (`transition:none`) but hide/show logic unchanged - **REMAINING** |
| Any modal `.modal-overlay:not([hidden])` open | visible or hidden irrelevant (overlay z-index above); do not toggle while open (optional) |

Required additions:
1. CSS (after the header rules): 
```css
.site-header:focus-within { transform: none; }
@media (prefers-reduced-motion: reduce) { .site-header { transition: none; } }
html { scroll-padding-top: calc(var(--header-height) + 8px); }
```
2. JS: in the rAF callback, `if (header.contains(document.activeElement)) { header.classList.remove("header-hidden"); ... reset lastScroll; return; }`; also `header.addEventListener("focusin", () => header.classList.remove("header-hidden"))`.
3. Keep the existing rAF `rafPending` throttle (H10 already DONE). No `setTimeout` debounce. Add small hysteresis: ignore |delta| < 4px to avoid jitter (optional, recommended).
4. `#main-content` skip target must not sit under the sticky header: `scroll-padding-top` above handles it.
