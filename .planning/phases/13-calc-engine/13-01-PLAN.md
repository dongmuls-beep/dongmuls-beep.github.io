## Assumptions (no CONTEXT.md for this phase — recorded here)

- A1: Fee input is the 실부담비용 value as stored in data.json, i.e. a percent number (0.5 means 0.5% per year). Engine divides by 100. (Research pitfall 6.)
- A2: Monthly model, per month m = 1..N (N = years*12), starting balance B = lumpSum:
  1. grown = B * g, where g = (1 + r)^(1/12), r = annualReturnPct/100
  2. feeThisMonth = grown * (1 - h), where h = (1 - f)^(1/12), f = feePct/100; totalFees += feeThisMonth
  3. B = grown * h + monthly (contribution at END of month, after growth and fee, so the final month's contribution earns nothing and pays no fee)
  The no-fee path runs the same loop with h = 1: B0 = B0 * g + monthly.
- A3: totalFees = nominal sum of monthly fee deductions (won, not discounted). costDrag = fvNoFee - fvWithFee (includes lost growth on fees, so costDrag >= totalFees when r >= 0; equal when r = 0).
- A4: Years: round to nearest integer, clamp to [1, 50]; non-finite years -> 1. lumpSum and monthly: non-finite or negative -> 0. annualReturnPct: non-finite/missing -> 0 (default 0% per research "no forecast-looking default"); clamp to [-99, 100] so (1+r) stays positive.
- A5: Fee validity: fee must be a finite number with 0 <= feePct < 100. null / undefined / NaN / Infinity / non-number string -> excluded with reason "fee_missing"; finite but negative or >= 100 -> excluded with reason "fee_invalid". Never coerce missing to 0.
- A6: Engine returns unrounded floats. Rounding happens only at display (Phase 15).
- A7: No mutable module state; functions are pure. Browser global name is `CompareCalc` (does not collide with any script.js global — executor should grep script.js for `CompareCalc` to confirm zero hits; do NOT edit script.js).
