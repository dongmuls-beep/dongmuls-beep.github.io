<interfaces>
Contract this plan creates (plan 08 consumes exactly these names; no i18n inside the chart):
- niceTicks(min, max, count = 4) -> ascending tick values (step from 1, 2, 2.5, 5 x 10^k), first <= min, last >= max
- sampleIndexes(n, max = 400) -> ascending indexes; keeps 0 and n-1, evenly spaced; n <= max returns all
- buildModel(dates, values, width, height) -> { empty, width, height, plot: { left, top, right, bottom }, yMin, yMax, ticks: [{ value, y }], points: [{ i (source index), x, y, date, value }], linePath, areaPath }
  y domain: from min when min > 0.4 * max, else from 0; flat or all-zero series still yields finite coordinates; dates.length 0 -> empty true, points [], paths ""
- nearestIndex(points, x) -> index into points (not source index)
- moveCursor(idx, key, count) -> new idx; ArrowLeft -1, ArrowRight +1, Home 0, End count-1, PageUp -20, PageDown +20, clamped; other keys -> idx unchanged
- render(container, { dates, values, width, ariaLabel, keysLabel, formatTick(v) -> string, formatReadout(date, value) -> string }) -> replaces container children with:
  div.pf-chart-focus[tabindex=0][role=group][aria-label=keysLabel] > svg.cmp-chart-svg[role=img][dir=ltr][aria-label=ariaLabel][aria-describedby=pf-chart-table] (gridlines, .pf-axis labels, area .pf-area, line .pf-line, cursor line .pf-cursor-line, dot .pf-cursor-dot)
  then p.pf-readout (not a live region) showing formatReadout for the cursor point; default cursor = last point
Height: 240 when width < 640, else 320. Width = max(256, width).
</interfaces>
