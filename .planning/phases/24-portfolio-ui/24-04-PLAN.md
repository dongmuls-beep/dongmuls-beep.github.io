Contract this plan creates (plans 07-09 consume):
- PortfolioShell.SUPPORTED, PortfolioShell.LANG_META
- resolveLang(urlLang, savedLang, browserLang) -> supported code (browserLang is the first 2 letters, lower-case)
- interp(str, vars) -> replaces every {name} with String(vars[name]) when vars has it; unknown tokens left as-is
- makeT(packs, lang) -> t(key, vars): packs[lang][key], else packs.en[key], else packs.ko[key], else key; result passed through interp
- t(key, vars), lang() -> "ko", htmlLang() -> "ko-KR" (for Intl locales)
- ready: Promise resolved after the first translation apply (resolves even if packs fail, with t returning keys)
- init(): browser only, called automatically when `document` exists; node require must not touch the DOM
- Dispatches document event "etf:lang-changed" after every apply (first load included)
- Element ids used: languageSelect, primaryNav, .hamburger-menu, privacyPolicyLink, privacyModal, privacyModalClose
</interfaces>
