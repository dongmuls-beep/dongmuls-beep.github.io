<interfaces>
Shared validator contract (this plan OWNS it; plan 02 only consumes it):
- LIMITS (Object.freeze): QTY_MAX_DECIMALS 8, QTY_MAX_INT_DIGITS 12, JUMP_RATIO 0.4, MAX_ROWS 200
- normalizeCode(code) -> string: String(code).trim(); /^\d+$/ -> padStart(6,"0"); else toUpperCase(). Non-string/empty -> "".
- validateQty(qty) -> null | "QTY_FORMAT" | "QTY_NONPOSITIVE". Requires typeof string matching /^(0|[1-9]\d{0,11})(\.\d{1,8})?$/ (no exponent, sign, comma, leading dot, whitespace). Matches but Number(qty) <= 0 -> "QTY_NONPOSITIVE". Numbers (not strings) -> "QTY_FORMAT".
- qtyToNumber(qty) -> Number(qty) if validateQty(qty) === null, else NaN.
- validateDate(s, todayIso?) -> null | "DATE_FORMAT" | "DATE_INVALID" | "DATE_FUTURE". Format /^\d{4}-\d{2}-\d{2}$/; real date via Date.UTC round-trip (2025-02-30 invalid); s > todayIso is future. todayIso default = local calendar date of new Date() as YYYY-MM-DD (local, not UTC, so a KST morning date is not "future").
- compute(rows, prices, opts?) -> { dates, total, byCode, warnings, asOf }
  rows: [{ code, qty, startDate }]; prices: { [code]: { dates: [...], close: [...] } } (prices/{code}.json shape, keyed by normalized code); opts.todayIso optional, passed to validateDate.
  warnings: array of { type, code?, row?, date?, error? } where type in "invalid_row" | "no_data" | "non_finite" | "delisted" | "jump". row = 1-based input row index.

Existing pattern from compare-calc.js: IIFE with "use strict", frozen LIMITS, `if (typeof module !== "undefined" && module.exports) module.exports = X; else (globalThis||window).X = X;`
Existing test pattern from tests/compare_calc_check.js: "use strict"; require path/assert; approx(actual, expected, tol, label) helper; block-scoped `{ }` cases; plain assert, no framework.
