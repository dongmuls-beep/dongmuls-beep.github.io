# Milestone v1.6: ETF 평가금액 추이 대시보드

**Status:** ✅ SHIPPED 2026-11-21 (audit: tech_debt, 차단 갭 없음)
**Phases:** 21-25
**Total Plans:** 22 (21: 2, 22: 3, 23: 2, 24: 10, 25: 5)

## Overview

방문자가 로그인 없이 보유 ETF(종목·소수점 수량·보유 시작일)를 입력하면 시작일부터 오늘까지 일별 평가금액 추이를 `/portfolio/`에서 확인한다. 59개 종목 종가는 공공데이터포털 API에서 모아 `prices/{code}.json`으로 커밋하고, 계산·저장·화면은 바닐라 JS(신규 의존성 0)다. 시드: `.planning/seeds/SEED-001-portfolio-dashboard.md`.

감사: [v1.6-MILESTONE-AUDIT.md](v1.6-MILESTONE-AUDIT.md) (status tech_debt). 요구사항 22/22, 통합 6/6, E2E 1/1(정적 추적, 브라우저 확인 보류). pytest 483 + node 15.
