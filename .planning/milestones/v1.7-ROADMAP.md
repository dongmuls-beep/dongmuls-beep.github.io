# Milestone v1.7: 홈 서버 이전

**Status:** ✅ SHIPPED 2026-11-21
**Phases:** 26-28 (phase 디렉터리 없이 direct 실행)
**Total Plans:** direct (계획 문서 없음)

## Overview

일일 ETL(`etl_process.py`)과 시세 수집(`scripts/build_price_history.py`)을 집 Ubuntu 서버(nginx, systemd timer)에서 직접 실행한다. 사이트 서빙은 GitHub Pages 유지, 서버는 배치 실행과 push만 담당한다. 운영 문서: `server_ops.md`, 유닛·스크립트 원본: `deploy/`.

## Phases

### Phase 26: 서버 실행 검증

**Goal**: 서버에서 ETL과 시세 수집이 실제 비밀 값으로 성공한다
**Requirements**: SRV-01, SRV-02
**Plans**: direct

**Details:** ETL이 서버에서 종료 코드 0, `data.json`·`update-meta.json` 갱신. 시세 incremental 성공. 비밀 값은 서버 `~/.etf-env`(600)에만 존재. (KOFIA 추출은 `getRowData()` JS 방식으로 수정, 28b05ef.)

### Phase 27: 스케줄·동기화

**Goal**: 서버가 사람 개입 없이 매일 두 작업을 돌리고 결과를 안전하게 넘긴다
**Depends on**: Phase 26
**Requirements**: SRV-03, SRV-04, SRV-05
**Plans**: direct

**Details:** `etf-etl.timer`(09:00 KST, system), `etf-prices.timer`(14:30 KST, user), `Persistent=true`, 공용 lock, 실행 전 pytest·node 검사. 구현 결과: ETL과 시세 모두 서버가 deploy key로 `main`에 push, GitHub `Daily ETF Data Update`·`Daily ETF Price Update` 워크플로 비활성화(이중 실행 방지). 초기에 시세는 서버 로컬 보관이었으나 501ef94에서 push로 전환.

### Phase 28: 공개·보안 마감

**Goal**: 외부에서 안전하게 접근 가능하고 운영 방법이 문서로 남는다
**Depends on**: Phase 27
**Requirements**: OPS-01, OPS-02, OPS-03
**Plans**: direct

**Details:** OPS-01은 "서버에서 공개 서빙하지 않음, Tailscale ssh로만 접속(키 만료 해제)"으로 결정. NOPASSWD sudo 제거, ssh 비밀번호·root 로그인 차단, 자동 보안 업데이트 확인. 운영 문서 `server_ops.md`·`deploy/` (eabc3d9, 완료 표시 e53d812).
