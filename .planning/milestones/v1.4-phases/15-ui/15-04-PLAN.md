parseCompareCodes(rawParam, validCodes):
- validCodes is a Set of upper-cased code strings.
- Slice the input to 200 chars, split on ",", trim each token, and upper-case it.
- Skip empty tokens. A token matching CODE_RE and present in validCodes is kept if not already kept. Duplicates are silently ignored and are not reported as dropped.
- Anything else goes to dropped: token sliced to 12 chars, at most 10 entries, deduped.
- After the loop, `capped = kept.length > 4` and codes = the first 4.

findLowestIndexes(values):
